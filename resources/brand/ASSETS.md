# Asset provenance

- **Vector mark and icon exports:** geometric SVG reconstruction of the Snowztech snowflake/diagonal concept selected in this project. Exported to PNG from those vectors; no raster image embedded in the SVG.
- **Social preview:** original SVG composition using the website headline and Snowztech UI colors; raster export at 1200 × 630.
- **Farol screenshot:** unmodified `assets/screenshots/split.png` from the Farol repository (https://github.com/snowztech/farol). The screenshot-library README describes the shelf demo, with Claude Code reviewing `src/queue.ts` and a second pane showing git history. Source resolution: 2540 × 1520. The screenshot was visually reviewed before inclusion.

SVG sources are editable without a particular design application. Raster exports were produced with Sharp 0.34.5. Image generation was not used for the vector assets, social card, or product screenshot.
